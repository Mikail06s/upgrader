# Upgrader Clone — инструкция запуска

## 1. Установи Python
Скачай Python с https://www.python.org (рекомендую 3.10+).
При установке поставь галочку **"Add Python to PATH"**.

## 2. Установи MySQL
Скачай MySQL Community Server: https://dev.mysql.com/downloads/mysql/
При установке запомни:
- Имя пользователя (по умолчанию `root`)
- Пароль, который придумал

## 3. Создай базу данных
Открой MySQL Workbench, HeidiSQL или консоль MySQL и выполни:

```sql
CREATE DATABASE upgrader_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE upgrader_db;
```

Затем импортируй файл `schema.sql` (он создаст все таблицы и добавит стартовые скины).

## 4. Настрой подключение к БД
Открой файл `config.py` и впиши свои данные:

```python
DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',          # твой логин MySQL
    'password': 'ТВОЙ_ПАРОЛЬ', # твой пароль MySQL
    'database': 'upgrader_db',
    'port': 3306,
}
```

## 5. Установи зависимости Python
Открой терминал (cmd / PowerShell) в папке проекта и выполни:

```bash
pip install -r requirements.txt
```

## 6. Запусти сайт
```bash
python app.py
```

Открой браузер и перейди по адресу: **http://127.0.0.1:5000**

## 7. Как пользоваться
- Регистрация — даёт баланс **5000 ₽** и одну стартовую скину.
- Каталог — все доступные скины с ценами и картинками.
- Профиль — твой инвентарь, баланс, продажа скинов на маркет.
- Апгрейд — выбери скину из инвентаря и целевую скину, поставь ставку, крути шанс выигрыша.
- Маркет — покупай скины у других пользователей или выставляй свои.

## 🖼 Где вставить свои картинки скинов
Я добавил заглушки через `https://via.placeholder.com/...` — они отображаются как цветные блоки с названиями.

Чтобы вставить настоящие картинки CS2-скинов:

**Вариант А (быстро):** в файле `schema.sql` найди строки `INSERT INTO skins ...` и замени `image_url` на прямую ссылку на картинку, например:
```
'https://steamcommunity-a.akamaihd.net/economy/image/...'
```

**Вариант Б (через папку):** положи свои изображения в `static/images/skins/` и в шаблонах (например `index.html`) пропиши:
```html
<img src="{{ url_for('static', filename='images/skins/ak47_redline.jpg') }}">
```

## ⚠️ Важное предупреждение
Это учебный клон/прототип. Настоящие сайты с скинами связаны с азартными играми и требуют лицензий, защиты от мошенничества, интеграции со Steam API и т.д. Не используй этот код для реальных денежных ставок без соответствующих правовых и технических мер.
